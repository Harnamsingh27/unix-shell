## Overview

This is a public showcase for a custom Unix-like shell built in C for a systems programming project. The project focuses on command-line input, built-in shell commands, modular C programming, input/output handling, and Makefile-based compilation.

The full source code is kept private because this was completed as a school project. This repository is meant to show what the project does, what technologies were used, and what I learned, without publicly releasing the assignment code.

## Source Code Access

The source code for this project is stored in a private repository and is not publicly accessible.

This means the code cannot be opened, downloaded, copied, or cloned by the public.

## Features

* Interactive shell-style command prompt
* Built-in command support such as `echo` and `exit`
* Command input handling and validation
* Error handling for invalid or unsupported commands
* Modular C file structure using separate source and header files
* Makefile-based compilation
* Practice with low-level systems programming concepts
* Organized project structure for maintainability and testing

## Tech Stack

* C
* Unix/Linux command-line programming
* Makefile
* Header files
* Modular C programming
* Standard input/output handling

## Project Structure

The private source repository is organized with multiple C source files, header files, and a Makefile.

```text
PROJECT_FINAL/
├── README.md
└── src/
    ├── builtins.c
    ├── builtins.h
    ├── io_helpers.c

    └── Makefile
```

Note: The actual source files are not included in this public showcase repository.

## What I Learned

This project helped me understand how command-line programs are built at a lower level. I gained more experience with C programming, organizing a multi-file project, writing helper functions, using header files, compiling with a Makefile, and handling user input in an interactive program.

It also gave me practice debugging C code, testing edge cases, and writing cleaner modular code instead of keeping everything in one file.
